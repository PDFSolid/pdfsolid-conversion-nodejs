Runtime Notes
  • The Node.js SDK package supports Linux x86_64 and Windows x86_64 runtime directories.
  • The addon loads native libraries from lib/pdfsolid_conversion/vendor/<platform>.
  • initialize() uses the packaged resource directory when no resource path is provided.
  • Conversion APIs are synchronous. Use worker threads or child processes for high-concurrency server workloads.
  • Call release() after conversion work is complete so native SDK resources are freed.
